# Readandwrite
📌 Project Overview

This project demonstrates Python file handling using text files and binary files. It includes writing content to a text file, reading file content, appending new content, reading binary image data, and creating a copy of an image.

🚀 Features

Write to a File: Write text content into file.txt.

Read a File: Read and display the contents of file.txt.

Append to a File: Add new text without overwriting existing content.

Read Binary Data: Read binary data from grimjow.png.

Copy an Image: Create a new image file named grimjow_copy.png using binary file handling.
